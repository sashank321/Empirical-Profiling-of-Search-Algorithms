# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-30

### Added
- **Search Intelligence Lab**: Implementations for BFS, DFS, UCS, GBFS, A*, Dijkstra, IDDFS, and IDA*.
- **Constraint Intelligence Lab**: Implementations for Backtracking, Forward Checking, MRV, LCV, and Arc Consistency.
- **Decision Intelligence Lab**: Implementations for Minimax and Alpha-Beta Pruning.
- **Uncertainty Intelligence Lab**: Implementations for Bayes Rule, Bayesian Networks, and Sensor Fusion.
- **Python Backend Integration**: Robust Python Flask backend to handle heavy algorithmic computations seamlessly offloaded from the frontend.
- **Compare Mode**: Ability to run and visually compare different intelligence algorithms side-by-side.
- **Explainable AI Panels**: Detailed insights and step-by-step reasoning outputs for algorithm executions.
- **CSP Visualizations**: Interactive graph-based visualizations representing constraint satisfaction problems.
